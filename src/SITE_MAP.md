## 🎮 Special Effects

### Cursor States:
```
Default:     ○ (40px circle)
Pointer:     ⭕ (60px circle)
Text:        | (2px vertical line)
View:        ⭕ "View" (100px with text)
```

### Cursor Trail:
```
     △
   △   △        Geometric triangles
 △       △      Follow cursor movement
   △   △        Fade out & float up
     △          Black/10 opacity
```

```
🌈 Rainbow filter on entire page

⏱️  Auto-disable after 5 seconds
```
